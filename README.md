# Nequi Expense Tracker

Nequi Expense Tracker is a mobile application designed to help users manage their expenses and income by categorizing transactions received via SMS from the number "890886". The app provides a user-friendly interface for classifying transactions and visualizing spending patterns over different periods.

## Features

- **SMS Integration**: Automatically receives and processes SMS messages from "890886".
- **Push Notifications**: Notifies users upon receiving a relevant SMS, prompting them to classify the transaction.
- **Category Selection**: Users can categorize their expenses and income using predefined categories and subcategories.
- **Visual Analytics**: View expenses and income over different periods (monthly, weekly, annually) with visual representations.
- **Transaction Management**: Add, update, and manage transactions easily.

## Categories

The application uses the following categories and subcategories for classifying expenses and income:

- **Vivienda**: Arriendo, servicios públicos (agua, luz, gas), internet, mantenimiento del hogar
- **Alimentación**: Supermercado, restaurantes, cafeterías, snacks
- **Transporte**: Transporte público, gasolina, mantenimiento de vehículo, apps de movilidad
- **Educación**: Matrícula, libros, cursos online, materiales
- **Salud**: Seguro médico, medicamentos, citas médicas, gimnasio
- **Entretenimiento**: Cine, conciertos, videojuegos, streaming (Netflix, Spotify, etc.)
- **Tecnología**: Teléfono móvil, plan de datos, computador, accesorios
- **Ropa y cuidado personal**: Vestimenta, calzado, peluquería, productos de higiene
- **Finanzas**: Ahorros, inversiones, deudas, tarjetas de crédito
- **Social**: Salidas con amigos, viajes, celebraciones, regalos

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/nequi-expense-tracker.git
   ```
2. Navigate to the project directory:
   ```
   cd nequi-expense-tracker
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. For Android, ensure you have the necessary SDKs and tools installed. Open the project in Android Studio and run the app on an emulator or physical device.

## Usage

- Upon receiving an SMS from "890886", a push notification will appear.
- Tap the notification to classify the transaction using the category selector.
- View your transactions and analytics on the dashboard and transactions screens.
